## 🚀 Featured Projects

### ⚡ [CODEXA — Online Code Judge & Competitive Programming Platform](https://github.com)
> *React.js, Node.js, Express.js, MongoDB, Docker, OpenJDK 17, Monaco Editor, JWT*
- **Remote Execution Engine**: Built a remote code execution engine that compiles and runs user-submitted Java inside Docker containers (OpenJDK 17) launched from Node.js child processes, enforcing timeout and memory limits on every submission.
- **Driver-Code Assembly & Verdicts**: Automated driver-code assembly (Java import reordering, stdin/stdout normalization) and verdict checking: Accepted, Wrong Answer, TLE, Compilation Error.
- **Monaco Editor Integration**: Integrated Monaco Editor (VS Code engine) for syntax highlighting and live execution, with a categorized problem library, difficulty filters, and tag search.
- **Production APIs & Telemetry**: Built REST APIs with JWT authentication and role-based access, plus MongoDB schemas for submission tracking, telemetry, and user analytics dashboards.

### 🔍 [CVision — AI-Powered Resume Screener & Career Intelligence Platform](https://github.com)
> *React 19, Node.js, Express.js, Python FastAPI, Scikit-learn, Sentence-Transformers, MongoDB*
- **Dual-Service Architecture**: Built a resume screener with an Express.js backend and a separate Python FastAPI ML service, connected via IPC with dynamic port discovery.
- **Semantic Vector Matching**: Implemented semantic resume-to-job-description matching with Sentence-Transformers (all-MiniLM-L6-v2) and cosine similarity to compute ATS match scores, with a Scikit-learn TF-IDF fallback.
- **60+ Tech Alias Pipeline**: Built a skill-extraction pipeline mapping 60+ technology aliases with RapidFuzz and regex to flag missing skills and compare applicants against job descriptions.
- **Ollama LLM Feedback & Security**: Added personalized resume feedback using Ollama (Phi-3), and secured the backend with Helmet headers, rate limiting, and bcrypt/JWT-protected routes.

### 🧠 GenAI with Azure — Summer Trainee (JOVAC)
> *GLA University | June 2025 – July 2025*
- Built generative AI prototypes on Microsoft Azure using Azure OpenAI Service (GPT models), prompt engineering workflows, and system integration.
- Applied Retrieval-Augmented Generation (RAG) with text embeddings and vector search to ground responses in external knowledge bases and reduce hallucinations.
